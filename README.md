# TaskFlow

A full-stack task management application built with Next.js and React.

## Features

- Task creation and deletion
- Kanban board with three workflow statuses
- Task priority labels
- Dashboard statistics
- Responsive layout

## Tech Stack

- Next.js
- React
- JavaScript
- CSS

## Current Status

The initial frontend prototype is implemented.
Tasks currently use in-memory state and reset on page refresh.

## Planned Features

- MongoDB persistence
- User authentication and authorization
- Team workspaces
- Real-time collaboration
- Automated tests
