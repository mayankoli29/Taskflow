# Taskflow
Developed a full-stack task management platform using Next.js, React, Node.js, and MongoDB with workspace-based access control and collaborative task workflows.    Implemented real-time updates, indexed task queries, and automated tests; measured query latency and documented the results.

# TaskFlow

A full-stack task management application built with Next.js and React.

## Features

- Task creation and deletion
- Kanban board with three workflow statuses
- Task priority labels
- Dashboard statistics
- Responsive layout

## Tech Stack

- Next.js
- React
- JavaScript
- CSS

## Current Status

The initial frontend prototype is implemented.
Tasks currently use in-memory state and reset on page refresh.

## Planned Features

- MongoDB persistence
- User authentication and authorization
- Team workspaces
- Real-time collaboration
- Automated tests
